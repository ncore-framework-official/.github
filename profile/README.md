## Official public ecosystem

This organization is the **official public publication space for NCore Framework**.

Only public-safe repositories, documentation, packages and releases are published here. Private development repositories, internal GDDs, qualification material, build tooling, secrets and unpublished proprietary source code remain outside this organization.

### NCore Control

<p align="center">
  <img src="assets/branding/ncore-control-official.jpg" alt="NCore Control official logo" width="260">
</p>

Official Windows application for installing and managing NANOS / nanos world servers.

**Public version:** 1.0.0

- install a standard NANOS / nanos world server;
- manage multiple independent server instances;
- start and stop managed servers;
- operate several managed servers independently;
- create dedicated desktop shortcuts;
- manage NCore Control updates.

**[Product page](https://github.com/ncore-framework-official/ncore-control)** · **[Download 1.0.0](https://github.com/boubeur/ncore-framework/releases/tag/control-v1.0.0)**

### NCore Framework

A modular RP framework designed specifically for NANOS / nanos world.

The ecosystem is built around a small Core and independent official packages covering areas such as:

- characters and identity;
- economy and banking;
- jobs and organizations;
- vehicles and housing;
- police, EMS and government;
- UI, player systems and administration.

Official packages appear in this organization only when they are approved for public distribution.

## Français

**NCore Framework** est l'écosystème public officiel NCore pour NANOS / nanos world.

Cette organisation est réservée exclusivement aux contenus **publics et officiels** : dépôts de distribution, documentation utilisateur, packages validés et releases publiques.

Le développement privé, les GDD internes, les qualifications, les outils de build, les secrets et les sources propriétaires non publiées restent séparés de cette organisation.

### NCore Control 1.0.0

NCore Control est l'application Windows officielle permettant notamment :

- d'installer un serveur NANOS / nanos world standard ;
- de gérer plusieurs instances serveur indépendantes ;
- de démarrer et arrêter les serveurs gérés ;
- de faire fonctionner plusieurs serveurs indépendamment ;
- de créer des raccourcis Bureau dédiés ;
- de gérer les mises à jour de NCore Control.

**[Page produit](https://github.com/ncore-framework-official/ncore-control)** · **[Télécharger NCore Control 1.0.0](https://github.com/boubeur/ncore-framework/releases/tag/control-v1.0.0)**

Les autres packages officiels NCore apparaîtront dans cette organisation uniquement lorsqu'ils seront validés pour publication publique.
